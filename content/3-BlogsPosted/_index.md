### [Blog 1 - AI Traffic Analysis Dashboards in AWS WAF](3.1-Blog1/)

This blog introduces the new **AI Traffic Analysis Dashboards** feature in AWS WAF. It explains how organizations can identify AI crawlers, monitor AI-generated traffic, analyze access patterns, and better understand the impact of AI bots on web applications. I also shared my thoughts on why monitoring AI traffic is becoming increasingly important for modern cloud security.

### [Blog 2 - AWS Shield Advanced Attack Flow Logs for DDoS Monitoring](3.2-Blog2/)

This blog explores the new **Attack Flow Logs** feature in AWS Shield Advanced. It explains how detailed attack metadata can help security teams investigate DDoS incidents, identify attack sources, analyze mitigation actions, and integrate security data with services such as Amazon S3, CloudWatch Logs, Amazon Athena, and SIEM platforms.

### [Blog 3 - Modernizing KYC with Serverless & Agentic AI](3.3-Blog3/)

This blog summarizes an AWS Architecture Blog describing a modern KYC (Know Your Customer) solution built with serverless technologies, event-driven architecture, Retrieval-Augmented Generation (RAG), and Agentic AI. Besides presenting the architecture, I also analyzed it from engineering, security, compliance, and cost perspectives, highlighting both its strengths and practical challenges for real-world financial systems.
