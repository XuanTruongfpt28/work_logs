### Week 7 Objectives:
- Learn the fundamentals of AWS CloudFormation. 
- Understand the concept of Infrastructure as Code (IaC). 
- Practice deploying AWS resources using CloudFormation templates. 
- Learn how to automate infrastructure deployment and management on AWS.

### Week 7 Achievements:

- Understood the concept of Infrastructure as Code (IaC) and its importance in automating AWS infrastructure deployment. 
- Learned the main components of an AWS CloudFormation template, including:
  - Parameters 
  - Resources 
  - Outputs 
  - Mappings 
- Became familiar with writing CloudFormation templates using YAML. 
- Successfully created and deployed AWS resources using AWS CloudFormation. 
- Learned how CloudFormation Stacks are created, updated, and deleted. 
- Understood the purpose of Change Sets and Stack Events in reviewing infrastructure changes before deployment. 
- Gained hands-on experience in automating infrastructure deployment instead of creating resources manually through the AWS Management Console. 
- Completed all CloudFormation hands-on labs and developed a better understanding of Infrastructure as Code practices on AWS. 
- Built a solid foundation for learning CI/CD pipelines and automated application deployment in the following weeks.
