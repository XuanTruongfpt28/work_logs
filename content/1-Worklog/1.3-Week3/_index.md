### Week 3 Objectives:
- Understand the fundamentals of Amazon Virtual Private Cloud (VPC). 
- Learn how networking works within the AWS environment. 
- Create and configure a custom VPC. 
- Practice deploying AWS resources inside a VPC.

### Week 3 Achievements:

- Understood the purpose of Amazon Virtual Private Cloud (VPC) and its role in building secure and isolated cloud networks. 
- Learned the key networking components of a VPC, including: 
  - VPC 
  - Subnet 
  - Route Table 
  - Internet Gateway 
  - Security Group 
  - Network ACL 
  - Successfully created a custom VPC and configured both Public and Private Subnets. 
- Configured Route Tables and Internet Gateway to enable Internet access for resources in the Public Subnet. 
- Launched an EC2 instance inside the custom VPC and verified network connectivity through SSH. 
- Gained a basic understanding of the differences between Security Groups and Network ACLs and how they help secure AWS resources. 
- Learned how different networking components work together to allow communication between AWS resources while maintaining network security. 
- Completed all practical exercises related to Amazon VPC and gained confidence in designing a basic AWS network architecture.
