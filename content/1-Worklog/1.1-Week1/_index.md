### Week 1 Achievements:
During the first week, I became familiar with the learning environment and the workflow of the First Cloud AI Journey internship program. After attending the orientation session, I understood the overall learning roadmap as well as the requirements that I needed to complete throughout the internship. 

By studying the Cloud Journey materials, I gained a basic understanding of Cloud Computing and learned about the major AWS service categories, including Compute, Storage, Networking, and Database. Learning these service groups helped me better understand how AWS provides infrastructure and cloud services for different types of applications.

 This week, I successfully created an AWS Free Tier account and became familiar with the AWS Management Console. I learned how to navigate the console, search for AWS services, and access the resources required for hands-on practice. 
 
 I also installed and configured AWS CLI on my computer by setting up the Access Key, Secret Access Key, and Default Region. After the configuration was completed, I executed several basic AWS CLI commands to verify the connection between my local machine and my AWS account. 
 
 Regarding Amazon EC2, I learned the basic concepts of AMI, Instance Types, EBS, and Elastic IP before moving on to the practical exercises. I successfully launched my first EC2 instance, configured the Security Group, connected to the instance using SSH, and attached an EBS volume. During the practice, I encountered some issues with the Security Group configuration, but after reviewing the documentation and checking the settings carefully, I was able to resolve the problem. 
 
 By the end of the first week, I had built a solid foundation for using both the AWS Management Console and AWS CLI. I also gained a better understanding of the basic process of deploying and managing an EC2 instance on AWS. These experiences will serve as a strong foundation for learning more advanced AWS services in the following weeks.
