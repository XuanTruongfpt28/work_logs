### Kết quả đạt được tuần 10:

- Hiểu được mô hình Serverless Computing và những lợi ích khi triển khai ứng dụng không cần quản lý máy chủ. 
- Nắm được các thành phần chính của kiến trúc Serverless trên AWS, bao gồm: 
  - AWS Lambda 
  - Amazon API Gateway
  - Lambda Trigger 
  - CloudWatch Logs
- Thực hành tạo và triển khai thành công AWS Lambda Function. 
- Kết nối Lambda với Amazon API Gateway để xây dựng và triển khai một REST API đơn giản. 
- Hiểu được cách Lambda được kích hoạt thông qua API Gateway hoặc các sự kiện từ dịch vụ AWS khác. 
- Thực hành theo dõi quá trình thực thi của Lambda bằng Amazon CloudWatch Logs và kiểm tra các lỗi trong quá trình chạy. 
- Hoàn thành các bài thực hành về AWS Lambda và Amazon API Gateway theo lộ trình Cloud Journey. 
- Có thêm kinh nghiệm trong việc xây dựng các ứng dụng Serverless trên AWS và hiểu được cách các dịch vụ này phối hợp với nhau trong một hệ thống thực tế. 
- Xây dựng nền tảng để tiếp tục tìm hiểu các kiến trúc ứng dụng hiện đại và các dịch vụ AWS nâng cao.
