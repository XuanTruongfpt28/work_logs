### Kết quả đạt được tuần 8:

Hiểu được quy trình Continuous Integration và Continuous Deployment (CI/CD) trong phát triển phần mềm. 
- Nắm được vai trò của các dịch vụ AWS Developer Tools, bao gồm: 
  - AWS CodeCommit 
  - AWS CodeBuild 
  - AWS CodeDeploy 
  - AWS CodePipeline 
- Thực hành tạo và quản lý mã nguồn bằng AWS CodeCommit. 
- Thực hành cấu hình quá trình Build tự động bằng AWS CodeBuild. 
- Triển khai ứng dụng lên Amazon EC2 bằng AWS CodeDeploy. 
- Xây dựng thành công Pipeline kết nối các dịch vụ CodeCommit, CodeBuild và CodeDeploy thông qua AWS CodePipeline. 
- Hiểu được quy trình triển khai tự động khi có thay đổi trong mã nguồn, giúp giảm thời gian triển khai và hạn chế các thao tác thủ công. 
- Hoàn thành các bài thực hành về AWS Developer Tools theo lộ trình Cloud Journey và có thêm kinh nghiệm về quy trình CI/CD trên AWS. 
- Xây dựng nền tảng để tiếp tục tìm hiểu các kiến trúc DevOps và quy trình triển khai ứng dụng trên môi trường Cloud.
