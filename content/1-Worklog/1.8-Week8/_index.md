### Week 8 Achievements:
- Understood the concepts of Continuous Integration (CI) and Continuous Deployment (CD) in modern software development. 
- Learned the purpose and functions of the main AWS Developer Tools, including: 
  - AWS CodeCommit 
  - AWS CodeBuild 
  - AWS CodeDeploy 
  - AWS CodePipeline 
- Successfully created and managed a source code repository using AWS CodeCommit. 
- Configured automated build processes with AWS CodeBuild and learned how build specifications are executed. 
- Deployed an application to Amazon EC2 using AWS CodeDeploy and verified that the deployment process completed successfully. 
- Built an end-to-end CI/CD pipeline by integrating CodeCommit, CodeBuild, and CodeDeploy through AWS CodePipeline. 
- Observed how code changes automatically trigger the build and deployment process, helping reduce manual work and improve deployment efficiency. 
- Completed all hands-on labs related to AWS Developer Tools and gained practical experience with implementing CI/CD workflows on AWS. 
- Established a solid foundation for learning more advanced DevOps practices and automated cloud application deployment in the following weeks.
