Event 3

Summary Report: “FCJ Community Day - June 2026”

Event Objectives

  • Share practical knowledge about Artificial Intelligence (AI) Agent applications in modern cloud environments.
  • Introduce real-world use cases of Agentic AI in Cloud Operations, DevOps, HR, and Voice AI.
  • Demonstrate how AWS services can be combined with AI technologies to solve business challenges.
  • Provide insights into cloud career development and future technology trends.

Speakers

  • Steve Tran (Cloud Thinker) Career Path & AgenticOps
  • Hieu Nghi, Trung, Kiet (R AI) Voice AI Solutions
  • Nguyen & Bao (Cloud Kinetic) DevOps Agent
  • Truong & Minh Anh (Noventiq) AI Applications in HR
  • Toan & Nghi MCP Server Security Architecture

Key Highlights

Career Path & AgenticOps

  • Steve Trần shared his career journey from a student learning AWS to becoming a cloud technology founder.
  • Discussed how AI is changing the software engineering job market and the importance of learning AI-assisted development skills.
  • Introduced AgenticOps, an approach that applies AI agents to improve cloud operations.

Three major problems addressed by AgenticOps:

  • Incident Management: Faster troubleshooting and incident response.
  • Automated Code Review: Detecting issues before applications reach production.
  • FinOps Optimization: Improving cloud cost management.

Voice AI Architecture

  • Introduced two common Voice AI architectures:

    • Speech-to-Speech architecture.
    • Speech → Text → LLM → Text → Speech pipeline.

  • Demonstrated a voice agent using AWS Bedrock Agent Core and Knowledge Base.

  • Explained why the pipeline approach is more suitable for Vietnamese applications:

    • Better control over generated responses.
    • More effective tool-calling capability.
    • Current limitations of speech-to-speech models for Vietnamese.

Challenges in Vietnamese Voice AI:

  • Regional accents.
  • User interruption handling.
  • Voice recognition and user experience optimization.

DevOps Agent for Cloud Operations

  • Introduced AWS DevOps Agent to solve the problem of fragmented logs and manual incident investigation.
  • Presented six core capabilities:
    • Context learning.
    • Control mechanisms.
    • MCP-based integration.
    • Collaboration with external platforms.
    • Runtime-based operation model.

Four-step incident handling process:

  1. Incident classification.
  2. Root cause investigation.
  3. Solution recommendation.
  4. Long-term improvement suggestions.
  • Demoed a simulated DDoS attack on an ECS application where the agent analyzed logs, identified the root cause, and proposed solutions.

AI-powered HR Solutions

  • Discussed challenges in traditional recruitment processes:

    • Manual CV screening.
    • Subjective evaluation.
    • Security risks when using public AI tools.

  • Introduced AI assistants capable of:

    • CV analysis.
    • Job description generation.
    • Recruitment workflow automation.
    • Integration with enterprise data sources.

  • Demonstrated an AI workflow that evaluated multiple CVs based on job requirements and generated recruitment reports.

MCP Server Security Architecture

  • Discussed security risks when connecting AI applications with MCP servers through public networks:

    • DDoS attacks.
    • Man-in-the-middle attacks.
    • Service exposure risks.

  • Presented a secure private connection architecture using:

    • VPC Connection.
    • Interface Endpoint.
    • Private DNS with Route 53 Resolver.
    • Application Load Balancer with TLS encryption.

  • Demonstrated secure communication with MCP servers without exposing services publicly.

Key Takeaways

AI and Cloud Transformation

  • AI Agents are becoming an important technology for improving cloud operations and business workflows.
  • Cloud engineers need to understand how AI can be integrated into existing systems.
  • The combination of AWS services and AI enables more intelligent and scalable solutions.

DevOps and System Operations

  • AI-powered operations can significantly reduce the time required for troubleshooting.
  • Automated analysis helps engineers focus on higher-level system improvements.
  • Secure architecture design remains essential when adopting AI technologies.

Future Technology Trends

  • The future of software development will involve collaboration between humans and AI agents.
  • Engineers need to continuously improve their knowledge of cloud, AI, and automation.
  • Practical experience and the ability to apply AI tools will become increasingly important.

Applying to Work

  • Explore AWS AI services such as Amazon Bedrock for future projects.
  • Apply AI-assisted tools to improve development productivity.
  • Learn more about Agentic AI architectures and their applications in cloud environments.
  • Improve understanding of secure cloud architecture when integrating external AI services.
  • Apply DevOps automation concepts to improve system monitoring and incident response.
